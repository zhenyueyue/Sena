# Sena Spine Setup Pose 美术母稿规范 v1

> 当前目标：先做出一张“静止就足够好看”的 Sena 正式 Setup Pose。
>
> 这张图通过后，才进入 PSD 正式拆层、Spine 绑定和动画。美术 Gate A 不通过，不做骨骼。

## 1. 成品定位

不是：

- 普通角色立绘；
- 海报；
- 复杂动态姿势；
- 只适合正面看的纸片；
- 为了展示细节堆满装饰。

而是：

> 一张专门为 **Spine 3.8 Professional 全身 Q 版桌宠**设计的角色母稿。

它必须同时满足：

1. 单独看很好看。
2. 约 3 头身仍保持年轻女性感，不幼儿化。
3. 关节和衣物能被拆成 Spine 可绑定部件。
4. 左右方向都能扩展。
5. 320–420 px 桌面显示仍然有清晰识别度。

## 2. 构图

第一张正式母稿：

- 透明背景。
- 完整全身。
- 轻微自然 A Pose。
- 身体基本正面。
- 头部允许约 5–10° 的轻微 3/4 感，但不能妨碍左右眼、脸轮廓和刘海拆分。
- 双臂与躯干之间留出明显透明间隙。
- 双腿之间留出透明间隙。
- 手不要藏到裙摆后。
- 鞋必须完整露出。
- 长发不能遮死肘、手、膝、鞋。
- 蝴蝶结完整露出。

地面基线经过双脚最低点。

## 3. 比例

目标约 **2.8–3.2 头身**。

视觉重点：

- 头大，但不是婴儿头。
- 脖子短而存在。
- 肩膀窄。
- 胸腔和骨盆 compact。
- 腿短于传统二次元立绘，但不能变成两根圆柱。
- 手略大于纯写实比例，确保 300 px 高度时还能读动作。
- 鞋轻薄，禁止厚底平台鞋。

重点避免：

- 超大脑袋 + 极小身体的幼儿体型。
- 肩太宽导致“Q版大头成人身”。
- 腿过长重新变成 5–6 头身。
- 手脚小到做动作时看不见。

## 4. 脸

脸是最高优先级。

### 目标

- 柔和、梦幻、清醒中带一点困倦感。
- 年轻女性，而不是幼女。
- 眼睛大但纵向不能夸张到圆球。
- 紫粉色虹膜，深色外圈。
- 2–3 层玻璃感高光即可，不堆十几个亮点。
- 上睫毛精细，下睫毛克制。
- 鼻子很小，但侧面轮廓要存在。
- 嘴小而自然。
- 下巴柔和收窄，不做尖锥。
- 轻微腮红。

### 默认表情

```text
gentle + dreamy + attentive + slightly sleepy
```

不笑得很大，也不面无表情。

## 5. 头发

### 色彩

主色：

- 月光银白。
- 很淡的粉紫 / 丁香冷色偏光。

不要：

- 纯灰。
- 纯白无层次。
- 紫得像彩发。
- 大面积金属高光。

### 造型

- 超长发，到臀部以下。
- 后发形成柔软的大轮廓。
- 刘海轻盈，额头保留少量可见区域。
- 两侧必须有脸侧发束。
- 发梢不是一刀切。
- 大块长发设计时就考虑拆成 5–7 个主要质量块。

Setup Pose 中不要用狂风吹发。

## 6. 标志性水晶蝴蝶结

这是 Sena 第一识别点之一。

要求：

- 大。
- 淡紫。
- 半透明水晶 / 欧根纱质感。
- 蝴蝶形轮廓一眼可认。
- 中心结体清楚。
- 上翼、下翼、尾带层次清楚。
- 不要像普通布蝴蝶结。
- 不要完全对称得像 UI 图标，要有轻微自然差异。
- 不能把头压得更大、更幼。

默认放在后上方 / 侧后上方，以不遮脸为准。

## 7. 服装

正式基础服装：

> 月光 × 淡紫 × 冰蓝的水晶蝴蝶短裙装。

### 上身

- 白色 / 月白主色。
- 淡紫边饰。
- 精细但不碎的蕾丝或晶体边。
- 肩、袖口有可读的蝴蝶/水晶语言。
- 上衣轮廓保持 compact。

### 裙装

必须能拆为：

- 后裙层；
- 中裙层；
- 前裙左；
- 前裙中；
- 前裙右；
- 两侧雪纺 / ribbon；
- 水晶边饰。

裙摆整体偏短，外层半透明部分可以更长。

不要做巨大的礼服裙撑，否则 walk / sit / coding 都很难。

### 腿与鞋

- 淡色丝袜 / 连裤袜。
- 细小水晶丝带细节。
- 鞋型轻巧。
- 鞋底薄。
- 鞋头略圆润，适合 Q 版。

## 8. 装饰密度

桌宠最终很小。

因此：

### 必须保留

- 大蝴蝶结。
- 发色层次。
- 眼睛。
- 腰部主要水晶 / 蝴蝶核心。
- 裙摆大层次。
- 鞋的主要水晶轮廓。

### 可以减少

- 极小珠链。
- 细到 1 px 的蕾丝。
- 过多吊坠。
- 满身星星亮点。
- 每根发丝都单独描线。

原则：

> 缩到 350 px 高时看不到的装饰，不应该成为设计中心。

## 9. Setup Pose 的 Spine 预留

原画阶段必须主动给动画留空间。

### 手臂

- 上臂和袖子分层边界要自然。
- 肘部周围预留遮挡区。
- 前臂和手掌边界可以藏在饰带 / 袖口结构里。

### 腿

- 大腿根会被裙摆覆盖。
- 膝盖结构必须能弯曲。
- 小腿进入鞋/袜处有隐藏余量。

### 头

- 头底图必须包含被刘海覆盖的额头。
- 耳朵完整画出，即使被侧发遮住。
- 脸底不能把眼睛直接烘焙进去。

### 长发

- 后发需要隐藏的头顶连接区。
- 左右侧发独立。
- 大发束之间有重叠，旋转后不漏透明缝。

### 裙摆

- 每片内部要有能做 mesh deform 的有效面积。
- 多片之间重叠，不做“刚好拼边”。
